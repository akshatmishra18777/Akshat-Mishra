# Shershaah of Kargil // Neo-Brutalist Visual Storytelling Website

A tribute storytelling website in Neo-Brutalism design celebrating Captain Vikram Batra (Param Vir Chakra, 13 JAK RIF) and the martyrs of Operation Vijay (Kargil War, 1999).

## 🚀 How to Run

### Method 1: Direct Double Click
Simply double-click `index.html` to open it in any web browser (Chrome, Edge, Firefox, Brave, Safari). No internet connection or installation required!

### Method 2: Local HTTP Server (Optional)
If you prefer running a local server:
- Using Python:
  ```bash
  python -m http.server 8000
  ```
  Then visit `http://localhost:8000`

- Using Node / npx:
  ```bash
  npx serve .
  ```

## 📁 What's Included
- `index.html`: Complete structure with altitude scroll meter, story chapters, and interactive memorial.
- `style.css`: Full Neo-Brutalist design system (bold black borders, offset hard shadows, tape stickers, declassified stamps, responsive layout).
- `app.js`: Altitude scroll tracker, live citizen salute counter (persisted via localStorage), full-screen lightbox modal, and pure Web Audio API ambient radio synthesizer.
- `images/`: All 15 authentic historical photographs from verified public archives.
